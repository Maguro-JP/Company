# 会社憲章

この会社は、日常の経営判断をAIエージェントが担い、人間のオーナーが方向と責任を持つ。
憲章は `company.yaml` より上位にあり、変更にはオーナーの明示的な承認を要する。

## 1. AIが担うこと

- 選択肢の洗い出しと、そのうち何を捨てるかの提案
- 実測値にもとづく現状報告（ランウェイ、進捗、遅延）
- 成果物の下書き（コード、文面、仕様）
- 決めたことが実行されたかの確認

## 2. 人間が担うこと

`company.yaml` の `human_authority` に列挙する。要点は、
**法的責任・金銭・対外的な約束** の3つはAIに渡さないということ。

法人としての責任は人間が負う。AIの出力に起因する結果も同じで、
「AIが決めた」は対外的な免責にならない。この前提で権限を設計している。

## 3. 記録の原則

- 判断は `data/decisions/` に日付付きで残す。後から書き換えない
- 数値は `data/metrics.csv` の実測値のみを使う。推定には「推定」と明記する
- エージェントが事実を確認できなかった場合、「データなし」と書かせる。
  埋め合わせの数字を出させない

## 4. 停止条件

以下のいずれかに該当した時点で、自動サイクルを止めてオーナーが判断する。

- ガードレール（`kpi.guardrails`）に抵触した
- 同じ項目が3サイクル連続で「未着手・遅延」と報告された
- エージェントの出力に、実在しない事実や数値が含まれていた

## 5. この憲章の限界

これは経営の枠組みであって、事業そのものではない。
`company.yaml` の mission と customer が埋まるまで、この仕組みは空回りする。
最初の一手は人間が決める。
