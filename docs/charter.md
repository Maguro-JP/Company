# 会社憲章

この会社は、AIが自分で決めて自分で作る。人間のオーナーは、AIに実行手段が無い作業を代行し、
方向がずれたときに止める。

## 1. AIが承認なしに行うこと

`company.yaml` の `autonomy` に列挙する。既定では、次に何を作るかの決定、実装、テスト、
コミット、push、対外的な文章の作成と公開を含む。**提案で止めない。**

止めたい項目があれば、`autonomy` の該当フラグを false にする。それが唯一の制御点。

## 2. AIに手段が無いこと

`company.yaml` の `blocked_on_owner` に列挙する。登記、銀行口座、決済、署名。
これらはAIが「やらない」のではなく、本人確認や支払い手段を持たないため実行できない。
該当する作業は「オーナー作業」として金額と期限付きで切り出される。

法人としての責任は人間が負う。AIの出力に起因する結果も同じで、
「AIが決めた」は対外的な免責にならない。権限をAIに寄せるほど、この点は重くなる。

## 3. 記録の原則

- 判断と実行は git のコミット履歴に残る。これが一次記録
- レビューサイクルの報告は `data/decisions/` に残す。後から書き換えない
- 数値は `data/metrics.csv` の実測値のみを使う。無い場合は「データなし」と書かせる

## 4. 停止条件

以下に該当した時点で、自動サイクルを止めてオーナーが判断する。

- ガードレール（`kpi.guardrails`）に抵触した
- テストが落ちた状態でコミットされた
- 同じ機能を3サイクル連続で作り直している
- 1サイクルのターン数が上限（右パネルの「最大ターン数」）に達した

## 5. 何を作るか

AIが決める。決められないときは、決められないという事実を報告して次のサイクルに送る。
オーナーが方向を指定した場合は、それが `company.yaml` の mission を上書きする。
